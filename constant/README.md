# constant 包 (`/constant`)

该目录仅用于放置全局可复用的**常量定义**，不包含任何业务逻辑或依赖关系。

## 职责边界

- 跨包共享且语义稳定的枚举、协议值、context key、cache key 和进程级启动常量可以放在这里。
- 与单一 feature 绑定的常量优先留在该 feature 包，避免把 `constant` 变成无边界的全局仓库。
- 文件和符号清单以源码为准，不在本文复制维护；按概念查找时直接搜索 `constant/`。

## 使用约定

1. `constant` 包**只能被其他包引用**（import），**禁止在此包中引用项目内的其他自定义包**。如确有需要，仅允许引用 **Go 标准库**。
2. 不允许在此目录内编写任何与业务流程、数据库操作、第三方服务调用等相关的逻辑代码。
3. 新增类型时保持命名语义清晰；如果它表达业务流程而不是稳定协议值，应放回拥有该流程的包。

> ⚠️ 违反以上约定将导致包之间产生不必要的耦合，影响代码可维护性与可测试性。请在提交代码前自行检查。
